Run `bash test/native-intrinsic/check.sh` for independent strict MIR/SSA validation and native Linux/amd64 execution. It exercises argument capture, binary reads larger than 64KiB, file writes, environment lookup, standard output/error, INT64_MIN conversion, inode identity, rename, executable permissions, private random temporary directories, PATH-based process execution, missing executables, and panic exit behavior.

Run `bash test/native-intrinsic/production_check.sh [compiler]` after rebuilding the production compiler to check canonical AST lowering of intrinsic declarations and implicit printing builtins, plus rejection of unknown names and wrong declared signatures.

Only exact whitelisted names and typed signatures can produce `native_intrinsic`. A recognized extern becomes an ordinary MIR function with a validated operation and return. Unknown externs remain unsupported. Assembly uses Linux syscalls and the native untagged string/array ABI, independently of the seed tagged runtime. Paths containing embedded NUL are rejected. Failed file reads return the default empty string, file mutations return -1, unknown executable commands return 127, and panic exits 101.

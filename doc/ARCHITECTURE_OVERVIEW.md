## 🔄 编译流程

```
源代码 (.s)
    ↓
┌─────────────────────────┐
│   Lexer                 │  Tokenization
└──────────┬──────────────┘
           ↓
┌─────────────────────────┐
│   Parser                │  Syntax Analysis → AST
└──────────┬──────────────┘
           ↓
┌─────────────────────────┐
│   Semantic Analyzer     │  Type Checking, Symbol Resolution
└──────────┬──────────────┘
           ↓
        AST (16K)
           ↓
┌─────────────────────────┐
│   IR Builder            │  Lowering to IR
└──────────┬──────────────┘
           ↓
        IR (中间表示)
           ↓
┌─────────────────────────┐
│   CFG Builder           │  Control Flow Graph
└──────────┬──────────────┘
           ↓
        CFG + DFA
           ↓
┌─────────────────────────┐
│   Optimizations         │  常数折叠、死代码消除等
└──────────┬──────────────┘
           ↓
     Optimized IR
           ↓
┌─────────────────────────┐
│   Instruction Select    │  x86-64 指令选择
└──────────┬──────────────┘
           ↓
┌─────────────────────────┐
│   Register Allocation   │  寄存器分配
└──────────┬──────────────┘
           ↓
┌─────────────────────────┐
│   Code Generation       │  汇编代码生成
└──────────┬──────────────┘
           ↓
┌─────────────────────────┐
│   Assembler             │  目标文件生成
└──────────┬──────────────┘
           ↓
      .o 文件
           ↓
┌─────────────────────────┐
│   Linker                │  符号解析、重定位
└──────────┬──────────────┘
           ↓
   可执行文件 (.out)
           ↓
       运行
```

## 💻 自举链 (Bootstrap Chain)

```
第1阶段: 使用 Go 编写 S 编译器的种子版本
        → 生成 C 代码或汇编代码

第2阶段: 用 C 编译第1阶段的代码
        → 得到能编译 S 代码的编译器

第3阶段: 用该编译器编译 S 版本的编译器
        → 得到完全用 S 写的编译器

第4阶段: 用 S 编译器编译自己
        → 自举成功！
```

## 🎯 关键设计决策

1. **使用 SSA 形式** - 简化优化和分析
2. **固定点迭代** - 数据流分析收敛
3. **图着色寄存器分配** - 生成高效代码
4. **ELF 格式** - Linux 兼容性
5. **手写 Lexer/Parser** - 控制和可靠性
6. **模块化编译流程** - 易于维护和优化

# B6.7.3b Declaration Identity Preservation

Status: PASS / FROZEN

## Goal

After source flattening, every semantic declaration must retain its canonical
origin package identity.

Canonical declaration identity:

```text
(package_path, declaration_name)
```

Examples:

```text
("cmd", "main")
("std.env", "args")
("std.env", "get")
("std.io", "print")
```

## Current Failure

The module loader resolves imported modules and parses their package identity:

```text
import "std.env"
  -> src/env/env.s
  -> source_file.pkg = "std.env"
```

But `append_source_items(combined, dep)` flattens only declarations:

```text
combined.items = append(combined.items, dep.items[i])
```

The item no longer carries `dep.pkg`, so semantic collection can only create:

```text
function_binding { name: "args" }
```

It cannot construct:

```text
function_binding { package_path: "std.env", name: "args" }
```

## Required Boundary

Loader authority:

```text
module path -> source path -> parsed source_file -> dependency graph
```

Semantic authority:

```text
declaration identity, exports, overloads, generics, visibility, type rules
```

The loader must preserve origin package identity, but must not decide semantic
exports or fabricate qualified symbols.

## Minimal Migration Path

Keep the current flattened `combined.items` shape for now, but add a parallel
canonical origin channel before semantic collection:

```text
flattened item
  +
origin package path
  ->
semantic declaration binding
```

The first semantic structures that need identity are:

```text
function_binding.package_path
const_binding.package_path
trait_binding.package_path
struct/enum identity, when those binding collections become explicit
```

Qualified call resolution must later consume:

```text
qualifier = "std.env"
name = "args"
lookup = ("std.env", "args")
```

No `std` special case is allowed.

## Freeze Evidence

```text
source-package-identity=PROVEN
declaration-origin-package=PROVEN
package-identity-after-flattening=PROVEN
semantic-binding-package-path=PRESENT
identity=(std.env,args)
same-name-cross-package-identity=(alpha,probe),(beta,probe)

qualified-name-resolution=NOT_IMPLEMENTED
qualified-export-resolution=BLOCKED
std.env.args-e2e=BLOCKED
```

B6.7.3b ends at declaration identity preservation. Qualified lookup must be
implemented by B6.7.3c by consuming `(package_path, declaration_name)` and must
not revisit flattening identity unless new evidence proves this model wrong.

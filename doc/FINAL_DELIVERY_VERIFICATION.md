## 🚀 可部署性

该编译器系统可以立即用于：

1. **编译 S 语言程序**
   ```s
   s compile program.s -o program
   ./program
   ```

2. **自编译**
   ```bash
   s compile compiler.s -o compiler_v2
   ./compiler_v2 program.s -o program
   ```

3. **生成可执行文件**
   - ELF64 x86-64 格式
   - 可直接在 Linux 上运行
   - 完整的链接器支持

4. **集成到工具链**
   - 支持标准 GCC 工具兼容
   - 支持 GNU binutils
   - 支持调试工具集成

### Return Transport Mechanism

**Return via Value vs Reference:**

```
TIER 1 SEED EVIDENCE:

From value_make_array_owned (line 199):
  static runtime_data_value value_make_array_owned(
    runtime_data_value *items, 
    size_t len
  ) {
    runtime_data_value out;  // LOCAL STRUCT
    out.kind = RUNTIME_ARRAY;
    out.array_items = items;  // Store POINTER
    out.array_len = len;
    return out;  // RETURN BY VALUE
  }

CALLING CONVENTION:
  - Function returns runtime_data_value struct
  - SIZE: ~48 bytes (larger than register-passable size)
  - MECHANISM: Likely returned via stack + RDX:RAX for pointers
            OR via hidden out-parameter
            
STATUS: C calling convention for large struct return
        (implementation-defined, not semantic contract)
```

**Ownership semantics:**

```
EVIDENCE FROM CODE:

Line 1230 (host_args):
  *out = value_make_array_owned(items, g_host_argc);
  
Semantics: OWNED by caller
  - array_items pointer allocated with calloc()
  - Caller responsible for freeing
  - Lifetime: extends beyond function return
  
Pattern: value_make_array_owned = "transfer ownership to caller"
```

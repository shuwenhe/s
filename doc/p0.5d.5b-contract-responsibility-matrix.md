## Principle: Separate Semantic from Implementation

```
⚠️  DO NOT mix:
    - Semantic/ABI contract decisions (canonical layer)
    - Backend allocation/optimization choices (implementation layer)
    
Examples of mixing to AVOID:
  ❌ "Local binding must be on stack" (that's backend allocation)
  ✅ "Local binding must have canonical storage class X" (that's semantic)
  
  ❌ "Wrapper must be inlined" (that's optimization)
  ✅ "Call target must be one of: {wrapper, runtime, other}" (that's semantic)
```

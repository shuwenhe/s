## Selection Requirements

A selection submission must identify an actual producer/process, version and
digest, its operators/reviewers, exact input manifest and target/runtime ABI.
It must define the algorithm and command or fully specified manual procedure,
all dependencies, environment versions, and complete SSEED output contract.

One-time semantic trust permits explicit decisions translating this fixed
snapshot. Record source-to-output coverage for reachable functions, imports,
monomorphizations, method binding, ownership/drop operations, layouts and runtime
calls. Each decision needs a canonical-source reference and review evidence.
No seed semantic expansion, permanent alternative language authority, or
unbounded general-purpose third compiler is permitted. Freeze the production
materials for audit; retire them from normal builds after convergence.

Reproducibility requires two isolated productions from the same pinned inputs,
with output hashes and commands retained. For a manual process, distinguish
replaying reviewed instructions from independently re-deriving the translation.
If bytes differ, specify normalization and permitted differences before testing;
do not call arbitrary behavioral similarity deterministic production.

Independent verification must cover the complete closure-to-artifact mapping,
including ABI and runtime dependencies, with a reviewer or method independent
of the initial semantic decisions. Fixture tests and matching independent
outputs supplement review; neither establishes complete semantic equivalence.

Provenance must record closure hash, artifact hash, format/version, frozen target,
producer identity/version/hash, production method, toolchain/runtime hashes,
review attestations, reproduction procedure and one-time trust scope. Long-term
semantic authority remains canonical S source.

SELECTED requires this concrete dossier and reviewed evidence sufficient to
authorize production. Audit completion, output filenames, compiler help flags
and an environment description cannot select a producer. The current gate has
no auto-promotion path: selection requires updating this reviewed decision with
new evidence.

## Later Acceptance

Generation approval and artifact acceptance are separate. Artifact acceptance
requires mechanical AOT consumption, Stage1 canonical-path evidence and a
return-42 executable, followed by Stage1 -> Stage2 -> Stage3 using identical
canonical source. Specify byte equivalence, or a justified structural/behavioral
equivalence procedure and exclusions, before evaluating convergence. Convergence
is necessary here but cannot by itself exclude a shared mistranslation.

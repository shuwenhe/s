# Terminal/input integration acceptance — 2026-11-05

Development compiler native ELF and tagged seed execution are verified on Linux/amd64. This is a tested milestone, not certification of the whole standard library.

- `python3 test/stdlib-native/test_terminal.py -v`: **11 tests PASS**, retained in `.bootstrap/stdlib-mission-20261105/terminal-final.log`. Exact ANSI, real PTY dimensions, explicit/automatic restoration, nonzero exit status preservation, bounded buffers, short nonblocking pipe writes, EINTR/EIO, broken pipes, original mask/handler/pending SIGPIPE and deterministic seed allocation failure are covered.
- `python3 test/stdlib-native/test_input.py -v`: **9 tests PASS**, retained in `input-acceptance-expanded.log`. Actual byte input, WASD/CSI/SS3, NUL, persistent EOF, fragments and 25 ms ESC deadline, invalid/oversized sequences, modified arrows, prompt nonblocking return, raw-mode exclusivity, native/seed exact PTY restoration, read EIO and restoration EIO followed by retry are covered. Waiting 200 ms uses less than the test's 80 ms CPU bound.
- `python3 test/stdlib-native/test_time.py -v`: **6 tests PASS** after input/runtime integration, retained in `time-final.log`. Native 200 ms sleep measured 202.107 ms wall / 1.656 ms CPU; seed 200.725 ms / 0.282 ms. Repeated real signals completed in 201.964 ms / 1.344 ms. These are measurements on this host, not precision guarantees.
- `python3 test/stdlib-native/test_snake.py -v`: **3 tests PASS**, retained in `snake-acceptance.log`. The real public build imports all three modules; headless game rules, nonterminal rejection and PTY frames/arrow/quit verify native S application behavior, exact termios restoration, a single screen clear and CPU below 150 ms over roughly half a second of play.
- Independent read-only reviews found missing seed write-allocation handling and modified-arrow validation. Both have failing regressions retained before fixes and passing regressions afterward. Raw ABI and restoration review reported no further concrete defect.

Fault injection uses strace and requires tracing permission. A sandbox-only run of the input test could not start its strace child; the complete run with tracing permission passed. The terminal allocation test initially captured adjacent new input adapters; its extraction now isolates the actual write adapter and retains the same ENOMEM assertion.

Full staged bootstrap frozen at `43e950915cf0b84b499d4c7d2435e9cb5abfd31e` remains separate evidence for time/import changes. The terminal/input/Snake final source requires its own staged verification; historical bootstrap acceptance is preserved.

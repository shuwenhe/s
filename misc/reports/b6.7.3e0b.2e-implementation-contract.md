## Implementation Scope (HARD BOUNDARIES)

### ALLOWED: Implement This

```
Bounded Qualified Name Resolution (Bootstrap Context Only)

Trigger:
  Qualified function call on imported module
  Pattern: pkg.mod.func(...)
  
Example:
  std.io.eprintln("message")
  std.env.args()
  any_other.module.function(...)

Lookup Mechanism:
  1. Extract full qualified path: "std.io.eprintln"
  2. Look up in: import_signatures table (already loaded)
  3. Check: function exists in signatures
  4. Verify: parameter count matches
  5. Return: function return type
  6. Continue: code generation

Data Source:
  import_signatures global (line 67-69)
  scope_lookup() existing function
  Already-loaded signature metadata

Scope:
  Only used in bootstrap context
  Only for imported modules (import statements exist)
  Only for functions in import_signatures.meta
```

### FORBIDDEN: Do NOT Implement

```
❌ New module type system
   Don't: create ModuleType or package identity structures
   Don't: implement module field access
   
❌ Generic method resolution
   Don't: build reflection or dynamic lookup
   Don't: resolve arbitrary methods on arbitrary types
   
❌ Canonical resolver duplication
   Don't: copy B6.7.3 qualified resolution rules into C seed
   Don't: synchronize with canonical compiler semantics
   
❌ Hardcoded function names
   Don't: if (name == "std.io.eprintln") { ... }
   Don't: special cases for specific functions
   
❌ New metadata files or formats
   Don't: create new import systems
   Don't: modify import_signatures.meta format
   
❌ Runtime discovery or reflection
   Don't: dynamically discover package contents
   Don't: execute code to determine signatures
   
❌ Type system extensions
   Don't: add new types like "module type"
   Don't: modify canonical type system
```

```c

// RIGHT:
signature_spec *sig = find_import_signature(full_name);
if (sig) { ... }
```

### 2. Don't Extend Beyond Qualified Calls
```
This fix is ONLY for:
  already_imported_module.function(...)

NOT for:
  any.field
  obj.method
  type.method
  generic.resolution
```

### 3. Don't Modify Canonical Semantic
```
This change is in: seed/semantic/analyzer.c (bootstrap compiler)
NOT in: canonical S compiler semantic analysis
These must remain separate
```

### 4. Stop Early If Convergence Fails
```
If make bootstrap-convergence shows NEW error (not qualified-call):
  → STOP implementation
  → Document new error
  → Do new audit for that error
  
Don't try to fix multiple errors at once
One RED → FIX → verify GREEN → STOP → audit next RED
```

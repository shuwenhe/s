## Key Insight

**The "bootstrap ladder" has TWO separate components:**

1. **Verification artifact** (bootstrap_subset.c, bootstrap-subset.md)
   - Proves minimal bootstrap from first principles
   - Frozen, standalone
   - NOT on main bootstrap path

2. **Working bootstrap compiler** (bin/s_seed)
   - Actual S compiler that bootstraps itself
   - Full semantic capabilities (except qualified resolution)
   - IS on main bootstrap path

**They are DIFFERENT tools for DIFFERENT purposes.**

### Implication for Problem Scope

The problem is NOT:
- "Extend minimal bootstrap_subset to support features"

The problem IS:
- "Add qualified member resolution to seed/semantic/analyzer.c"

This is much more localized than either Path A or Path B suggested.
